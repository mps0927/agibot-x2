# SDK references

`McPresetMotion.msg`와 `interface_manifest.json`은 설치 AIMDK `v1.0.0-ga424add`의 메시지 상수 및 서비스 스키마 SHA-256 목록이다. 전체 SDK 설치본·바이너리·기기 로그·매뉴얼 PDF·사진은 저장소에 포함하지 않는다.

- [제조사 AIMDK 문서](https://x2-aimdk.agibot.com/en/latest/)
- [프리셋 API](https://x2-aimdk.agibot.com/en/latest/Interface/control_mod/preset_motion.html)
- [X2 URDF](https://github.com/AgibotTech/agibot_x2_urdf)
- [OmniHand SDK](https://github.com/AgibotTech/agilink_omnihand_sdk)

URDF는 기구 모델, OmniHand SDK는 손 전용이다. 이 대시보드의 본체 제어는 X2 내부 AIMDK/ROS 서비스를 사용한다.
