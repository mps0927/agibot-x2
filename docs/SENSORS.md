# 카메라·센서 사용하기

대시보드 맨 위의 `센서 상세 ↗`를 눌러 [카메라·센서 페이지](http://127.0.0.1:8766/sensor)를 엽니다. 로봇을 연결하면 장치별 이름·위치·수신 상태가 자동으로 갱신됩니다.

1. `장치 목록`에서 사용할 센서를 찾습니다. `센서 찾기`에 이름·위치·종류를 입력해 검색할 수 있습니다.
2. 각 카드의 `현재 값 · 연결 정보`를 펼쳐 값을 확인합니다.
3. 카메라는 `영상 보기` 또는 상단의 `카메라 선택`에서 고릅니다. 선택한 카메라는 메인 대시보드에도 적용됩니다.
4. 목록과 현재 값을 내려받으려면 `현재 센서 값 저장`을 누릅니다.

메인 화면으로 돌아가려면 `← 대시보드`를 누릅니다. 라이다 점군과 VLM 입력은 메인 대시보드에서 확인합니다.

## 카메라 선택

센서 페이지의 `카메라 선택` 목록에서 선택하거나 센서 카드의 `영상 보기`를 누릅니다. 데이터를 제공하는 영상 소스를 선택하면 대시보드가 해당 카메라로 전환합니다.

| 화면 이름 | 위치·역할 | 확인할 데이터 |
|---|---|---|
| 머리 정면 RGB | 머리 정면 | 컬러 영상 |
| 전면 스테레오 왼쪽 | 머리 전면 왼쪽 | 왼쪽 컬러 영상 |
| 전면 스테레오 오른쪽 | 머리 전면 오른쪽 | 오른쪽 컬러 영상 |
| 후면 RGB | 머리 뒤쪽 | 후방 컬러 영상 |
| 전면 RGB-D | 머리 전면 | 깊이 카메라의 컬러 영상 |
| 전면 RGB-D · 깊이 | 머리 전면 | 거리별 밝기로 표시한 깊이 영상 |
| 렌즈 정보 | 해당 카메라 | 해상도, 내부 행렬, 왜곡 계수 |
| H.265 | 해당 카메라 | 동일 카메라의 다른 압축 영상 형식 정보 |

카메라 구성과 공개되는 영상은 로봇 모델·설치 소프트웨어에 따라 달라집니다. **로봇에서 데이터가 공개되기를 기다립니다**라는 항목은 발행 상태를 기다리는 항목입니다.

깊이 미리보기는 0~6m 범위를 밝기로 표시합니다. 가까운 물체가 밝고 유효 거리값이 없는 점은 검게 보입니다. 영상의 세부 인코딩은 해당 카드의 **현재 값 · 연결 정보**에서 확인합니다.

메인 대시보드의 `현재 프레임 사용`은 지금 보고 있는 카메라 프레임을 VLM에 전달할 이미지로 선택합니다. **프레임 업로드**는 PC에 저장한 이미지를 선택합니다. 카메라를 전환하면 이전 프레임과 실행 계획을 지우고 새 장면에서 다시 분석합니다.

## 라이다

가슴 전면의 LiDAR 점군은 로봇 연결 시 자동으로 검색·수신합니다. **LiDAR · X2 센서**에서 XY 점군, 수신 속도와 경과 시간을 확인합니다. **VLM에 점군 요약 함께 전달**을 선택하면 해당 요청의 요약·표본 좌표를 사진과 함께 기록합니다.

라이다 기본 데이터 이름은 `/aima/hal/sensor/lidar_chest_front/lidar_pointcloud`입니다. 토픽 입력이나 연결 버튼 조작 없이 실제 발행되는 라이다 데이터로 자동 연결합니다.

## 자세·관절·전원·기타 센서

| 센서 | 위치·역할 | 화면에서 확인할 값 |
|---|---|---|
| 가슴 IMU | 가슴 | 자세 quaternion, 각속도, 선형 가속도 |
| 몸통 IMU | 몸통 | 자세 quaternion, 각속도, 선형 가속도 |
| 라이다 IMU | 라이다 내부 | 각속도, 선형 가속도 |
| 스테레오·RGB-D IMU | 해당 카메라 내부 | 공개되는 자세·가속도 값 |
| 팔·다리·손·머리·허리 관절 | 각 관절 | 위치, 속도, 오류 등 관절 상태 |
| 배터리·전원 | 몸통 배터리 | 잔량·온도 등 전원 상태 |
| 머리 터치 | 머리 | 터치 이벤트·채널 상태 |
| 마이크 수신 | 머리 | 오디오 청크 길이·프레임·포맷 정보 |
| 스피커 상태·음량 | 머리 | 재생 상태·공개되는 음량 상태 |
| GNSS 위치 | GNSS 수신기 | 공개되는 위도·경도·상태 |
| 센서 모듈·관절 제어기 | 해당 장치 | 공개되는 진단·장치 상태 |

**현재 값 · 연결 정보**를 펼쳐 값을 읽습니다. 긴 배열과 오디오 버퍼는 항목 수로 요약하며, 현재 값 저장 파일에도 이 요약을 사용합니다. 배터리는 화면 맨 위에서도 확인할 수 있고 관절 각도는 **관절 상태**에서 슬라이더로 확인합니다.

## 상태 읽기와 저장

- **수신 중:** 실제 데이터를 받았으며 수신 속도와 경과 시간을 표시합니다.
- **연결 가능 · 영상 보기를 선택하세요:** 선택하면 영상을 구독하는 카메라입니다.
- **데이터 수신 대기:** 장치가 데이터를 제공할 준비가 되어 있고 새 메시지를 기다립니다. 일부 상태는 변경될 때 갱신됩니다.
- **로봇에서 데이터가 공개되기를 기다립니다:** SDK에서 발행자를 찾지 못한 항목입니다.
- **설치 SDK에 메시지 정의가 없습니다:** 현재 SDK 정의와 브리지가 제공한 데이터 설명으로 해석할 수 없는 항목입니다. 장비 담당자와 SDK·로봇 소프트웨어 조합을 확인합니다.

**현재 센서 값 저장**을 누르면 센서 목록, 시간, 수신 상태와 현재 요약값을 JSON 파일로 내려받습니다. VLM에 사용한 사진과 점군은 [요청 기록](USER_GUIDE_KO.md#records)에 별도로 보관합니다.

## 라이다가 계속 대기 중일 때

대시보드는 로봇 연결 후 자동으로 구독을 시도합니다. 프로젝트 폴더에서 다음 명령으로 로봇 SDK의 발행 상태를 확인합니다.

```bash
docker compose run --rm x2 doctor
```

직접 SDK의 `Publisher count: 0`이 나와도 브리지 경로에서는 수신할 수 있습니다. 대시보드의 **점군 수신 중**과 실제 점들을 함께 확인합니다. 두 경로에서 모두 데이터가 없으면 장비 담당자와 라이다·센서 앱의 공개 상태를 확인합니다.

센서와 인터페이스의 제조사 설명은 [AIMDK 센서 문서](https://x2-aimdk.agibot.com/zh-cn/latest/Interface/hal/sensor.html)를 참고합니다.
