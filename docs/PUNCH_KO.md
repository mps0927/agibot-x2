# X2 오른팔 펀치

대시보드의 `펀치 · 오른팔 동작 제작`을 펼치면 X2 오른팔의 준비 → 뻗기 → 회수 → 시작 자세 복귀 궤적을 확인할 수 있습니다.

## 동작 설계 확인

1. `펀치 · 오른팔 동작 제작`을 펼칩니다.
2. 시작 기준이 최근 조회 각도인지 영점 참고 각도인지 확인합니다.
3. `궤적 미리보기`를 눌러 측면 X-Z 관절 모양과 손목 경로를 확인합니다.
4. `설계 JSON` 또는 `궤적 CSV`로 동작 제작 참고 자료를 내려받습니다.

G1 펀치의 구간 구성과 시작 자세 복귀 방식을 참고해 X2 관절 목표를 별도로 정했습니다. X2 팔꿈치는 음수 방향으로 굽혀지고 0에 가까워지면 펴지므로 G1의 양수 팔꿈치 값을 그대로 사용하지 않습니다. 손가락 쥐기·타격 대상·접촉 동작은 포함하지 않습니다.

미리보기는 오른팔 7관절만 계산합니다. X2 URDF 관절 범위를 검사하고 5차 보간으로 구간을 연결합니다. 구간 시간은 관절 이동량과 설계 목표속도 상한 `2 rad/s`로 계산합니다. 이 수치는 G1 제작 기준을 참고한 값이며 실제 X2의 검증된 안전속도나 저장 모션 재생 속도를 뜻하지 않습니다. 그림은 손목 기준의 기구학적 경로이며 충돌·접촉·동역학을 검증한 결과는 아닙니다.

## 실물 재생 준비

현재 공개 SDK의 사용자 모션 API는 로봇에 등록된 모션을 조회·재생합니다. 펀치의 실물 재생은 **X2용 팔 모션을 제작·등록하는 단계**가 필요합니다.

1. 위 참고 자료를 바탕으로 제조사에서 지원하는 팔 모션 제작·배포 절차를 사용합니다. LinkCraft 계정·권한·지원 형식은 장비 담당자에게 확인합니다.
2. 오른팔 모션 이름을 정확히 `punch_right`로 등록합니다.
3. 로봇의 사용자 모션 목록이 갱신되면 대시보드에 `등록된 오른팔 펀치 실행`이 표시됩니다.
4. 로봇의 기립·안정 서기와 기존 제어 준비를 마친 뒤 등록 모션을 실행합니다.

SDK에서 이 이름의 팔 모션과 자원 키·버전이 확인되어야 실행 버튼이 표시됩니다. 전신 ONNX 모션은 이 펀치 버튼에 연결하지 않습니다. 실행은 기존 `ExecuteActionResource`를 사용하며, 내보낸 참고 JSON·CSV의 관절 목표를 직접 모터로 발행하지 않습니다. 참고 자료는 자체 형식이므로 LinkCraft에 그대로 가져올 수 있다고 가정하지 않습니다.

실물 재생 시 동작 내용과 시간은 로봇에 등록된 자원이 결정합니다. 등록한 자원이 위 설계와 일치하는지는 제작·검증 단계에서 확인합니다. 현재 제공된 궤적은 실물 재생 미검증 상태입니다.

## VLM에서 요청

등록된 `punch_right` 팔 모션이 조회되면 기존 사용자 모션 목록을 통해 VLM에도 전달됩니다. 지시 예시는 `오른팔 펀치 모션을 한 번 해.`입니다. 로봇에 자원이 등록되기 전에는 실행 가능한 펀치로 전달하지 않습니다.

## 개발용 조회

- `GET /api/punch`: 시작 기준, 구간별 관절 목표, 기구학적 미리보기와 자원 등록 상태
- `GET /api/punch?format=json`: 동작 제작 참고 JSON
- `GET /api/punch?format=csv`: 오른팔 7관절의 50Hz 표본 참고 CSV

이 조회·미리보기·내보내기는 로봇 제어 요청을 보내지 않습니다. 기존 MC 모듈을 중지하거나 저수준 관절 실행 제한을 해제하지 않습니다.
