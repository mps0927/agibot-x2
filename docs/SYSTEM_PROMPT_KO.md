# 시스템 프롬프트 실험 안내

실험자는 시스템 프롬프트를 원하는 목적에 맞게 수정해 모델의 판단과 응답을 비교할 수 있습니다. 기본 파일은 [x2_motion/prompts/x2_system_en.txt](../x2_motion/prompts/x2_system_en.txt)입니다. 이 안내는 대시보드의 OpenRouter 연결에서 사용하는 프롬프트를 설명합니다.

## 1. 바꿀 내용을 정합니다

| 실험 항목 | 수정 예시 |
|---|---|
| 역할 | 안내 로봇, 장면 설명 보조자 등 역할 설명 |
| 장면 해석 | 관찰한 사람·물체·위치 중 어떤 정보를 우선 설명할지 지정 |
| 동작 선택 | 지시가 모호하면 먼저 확인하도록 판단 규칙 지정 |
| 설명 방식 | 한국어 설명 길이, 표현과 근거 작성 방식 지정 |

예를 들어 다음 문장을 기본 프롬프트에 추가해 응답을 비교할 수 있습니다.

```text
장면 설명은 관찰한 사실만 한국어 두 문장 이내로 작성한다.
사용자 지시에 동작 대상이나 방향이 모호하면 plan_status를 clarify로 설정하고,
decision_reason에 필요한 확인 사항을 작성한다.
```

실행기는 정해진 JSON 형식의 응답을 해석합니다. 기본 프롬프트의 출력 필드 `scene`, `explanation`, `plan_status`, `decision_reason`, `actions`와 지원 동작 형식을 유지하며 실험 규칙을 추가·수정합니다. 실행 코드에서 허용하는 동작·속도·이동 시간·권한 조건은 프롬프트와 별도로 검사합니다.

## 2. 파일을 수정합니다

프로젝트 폴더의 명령 창에서 사용하는 기기에 맞는 명령을 실행합니다.

| 기기 | 파일 열기 | 저장 |
|---|---|---|
| Windows | `notepad x2_motion/prompts/x2_system_en.txt` | `Ctrl+S` |
| Mac | `open -e x2_motion/prompts/x2_system_en.txt` | `Command+S` |
| DGX Spark | `nano x2_motion/prompts/x2_system_en.txt` | `Ctrl+O` → Enter → `Ctrl+X` |

파일 이름과 경로는 유지하고 UTF-8 일반 텍스트로 저장합니다. 내용은 한국어 또는 영어로 작성할 수 있습니다. 이전 프롬프트를 보관하려면 편집 전에 별도 실험 폴더나 Git 브랜치에 복사해 둡니다.

## 3. Docker에 적용합니다

로봇 조작과 진행 중인 VLM 요청을 마친 뒤 프로젝트 폴더에서 실행합니다.

```bash
docker compose up -d --build
```

수정한 프롬프트를 포함한 이미지로 대시보드가 다시 시작됩니다. 브라우저에서 대시보드를 새로고침하고 연결 상태를 확인합니다.

Python으로 직접 실행하는 개발 환경에서는 요청할 때 프롬프트 파일을 읽습니다. 저장한 내용은 다음 모델 요청부터 반영됩니다. Docker 사용자는 위 빌드 명령으로 호스트에서 수정한 파일을 이미지에 반영합니다.

## 4. 반영된 내용과 응답을 확인합니다

1. 대시보드의 `시스템 프롬프트 · 요청 / 응답`을 펼칩니다.
2. `시스템 프롬프트 · 실제 ActionList 포함`에서 수정한 문구를 확인합니다.
3. 필요하면 `시스템 메시지 복사`를 눌러 실험 기록에 붙여 넣습니다.
4. 모델과 프레임을 선택하고 지시를 입력합니다.
5. `계획만 보기`를 눌러 실행 판단과 응답을 비교합니다.
6. `마지막 모델 요청 · system / user 원문`에서 방금 요청에 실제 사용한 메시지를 확인합니다.

화면에서는 시스템 프롬프트의 조회와 복사를 제공합니다. 편집은 위 텍스트 파일에서 진행합니다.

모델에 보내는 system 메시지에는 다음 내용이 순서대로 포함됩니다.

| 순서 | 내용 |
|---|---|
| 1 | 실험자가 수정한 기본 프롬프트 |
| 2 | 로봇에서 조회한 동작 목록과 명령 정의 |
| 3 | 현재 로봇 상태와 관찰 정보 |

프롬프트 실험을 비교할 때는 모델·입력 프레임·사용자 지시를 함께 기록합니다. 로봇의 상태와 제공 동작 목록도 요청 시점에 따라 달라질 수 있습니다.

## 5. 요청별 프롬프트를 기록에서 확인합니다

요청별 폴더의 `model_request.json`에 실제 system 메시지와 사용자 지시가 저장됩니다. Docker 안의 기록 위치는 다음과 같습니다.

```text
/data/artifacts/vlm_runs/<요청별 폴더>/model_request.json
```

파일의 `messages`에서 `role`이 `system`인 항목의 `content`를 확인합니다. 응답은 `model_response.json`, 입력 사진은 `input.jpg`에서 확인합니다. PC로 가져오는 명령과 전체 파일 설명은 [요청 기록 확인](USER_GUIDE_KO.md#records)을 따릅니다.

외부 VLM 서버를 `VLM_PIPELINE_URL`로 연결한 경우에는 그 서버가 모델 요청과 시스템 프롬프트를 구성합니다. 해당 서버의 설정에서 프롬프트를 관리합니다.

- [VLM으로 명령하기](USER_GUIDE_KO.md#vlm)
- [README로 돌아가기](../README.md#system-prompt)
