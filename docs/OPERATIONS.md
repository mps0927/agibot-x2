# 대시보드 현장 사용 순서

로봇을 사용할 PC와 X2를 LAN 케이블로 직접 연결해 진행합니다. Windows, Linux(DGX Spark 포함), macOS에서 같은 실행 명령을 사용합니다. Windows에서는 PowerShell, Linux와 macOS에서는 터미널 앱에 명령을 입력합니다.

처음 사용하는 PC는 [최초 설치 안내](FIRST_START_KO.md)를 완료합니다. 아래 명령은 `compose.yaml`이 있는 프로젝트 폴더에서 실행합니다. 버튼별 자세·지지 조건은 [대시보드 사용설명서](USER_GUIDE_KO.md)를 따릅니다.

## 시작하고 조종하기

최초 설정이 끝난 같은 PC·같은 유선 어댑터를 사용합니다. 새 PC에서는 [최초 설정](FIRST_START_KO.md)을 진행합니다.

1. 의자·양발 접지·보조자 지지를 준비합니다.
2. 배터리 전원 버튼을 짧게 1회 누른 뒤 약 5초 길게 누르고, 부팅을 약 1분 기다립니다.
3. PC와 로봇을 LAN으로 연결하고 Docker를 준비한 뒤 `docker compose up -d`를 실행합니다.
4. 같은 PC의 브라우저에서 [대시보드](http://127.0.0.1:8766)를 열고 `AGIBOT X2 연결됨`, 갱신되는 영상·배터리·현재 모드를 확인합니다.
5. 상단에서 지지 상태를 체크하고 **착석 자세 고정**을 누릅니다.
6. 의자·양발·보조자·기립 공간을 체크하고 **일어서기**를 누릅니다.
7. 안정 서기를 확인한 뒤 **제어 활성화**를 누릅니다.
8. 프리셋, 이동·회전 또는 VLM 명령을 사용합니다.

## 종료하기

1. 작업을 마치면 이동을 정지하고 프리셋의 실제 종료를 확인한 뒤 **제어 해제**를 누릅니다.
2. 현재 모드가 안정 서기인지 확인합니다. 의자 위치·양발 접지·보조자 지지 확인 항목을 체크하고 상단의 **의자에 앉기**를 누릅니다.
3. 완전히 앉은 뒤 **댐핑·영토크 / 모드 전환**을 펼쳐 **댐핑**을 선택합니다. 선택 모드의 자세·지지 조건을 확인하고 해당 항목을 체크한 뒤 **선택 모드 전환 요청**을 누릅니다.
4. 같은 영역에서 **영토크 · 힘 해제**를 선택하고, 지지 조건을 다시 체크한 뒤 **선택 모드 전환 요청**을 누릅니다.
5. 의자와 보조자가 로봇을 계속 지지하는 상태에서 PC에서 `docker compose down`을 실행합니다.
6. 배터리 전원 버튼을 짧게 1회 누른 뒤 약 5초 길게 눌러 전원을 끕니다.

## 화면과 센서만 확인할 때

같은 `docker compose up -d`로 실행하고 영상·배터리·관절·라이다를 확인합니다. 로봇 연결 전에도 화면을 열고 `프레임 업로드`를 사용할 수 있습니다. OpenRouter 키가 준비되면 `계획만 보기`로 AI 분석을 확인합니다. 로봇 전원과 LAN을 나중에 연결하면 자동으로 접속합니다.

## 연결이 안 될 때

`docker compose run --rm x2 network-check`로 유선 연결을 확인하고, 이어서 `docker compose run --rm x2 doctor`로 로그인·SDK를 확인합니다. [연결 문제 해결](FIRST_START_KO.md#connection-check)에 정상 표시와 오류별 조치가 있습니다.

`.env`를 수정했다면 조종을 끝낸 뒤 `docker compose up -d --force-recreate`로 반영합니다. 같은 로봇과 Docker 볼륨을 계속 사용할 때는 접속 키를 다시 등록할 필요가 없습니다.

리모컨으로 진행할 때는 [리모컨으로 A to Z](REMOTE_CONTROL_GUIDE_KO.md)를 참고합니다.
