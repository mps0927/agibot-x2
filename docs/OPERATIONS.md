# 현장 실행 순서

1. 로봇 전원·LAN·의자와 보조자 지지를 준비하고 PC에서 X2 개발 보드 `10.0.1.41`의 SSH 접속을 확인한다.
2. `.env`에 SSH 인증을 설정하고 `./start_field.sh`를 실행한다. 기본 웹 포트는 8766이다.
3. 화면 상단에서 이미 앉아 있는 로봇의 지지 상태를 확인하고 **착석 자세 고정**을 요청한다. 이미 `SIT_JOINT_DEFAULT`이면 명령을 반복하지 않는다.
4. 기립 공간·양발 접지·보조자 지지를 확인하고 **일어서기**를 요청한다. `STAND_DEFAULT` 모드와 실제 기립을 확인한다.
5. **제어 활성화** 후 프리셋 또는 이동 버튼을 사용한다. 프리셋은 실제 종료 후 현장 확인 버튼을 눌러 다음 동작을 준비한다.
6. 의자에 앉으려면 먼저 제어를 해제하고 상단 **의자에 앉기**를 사용한다. VLM은 기립·착석을 자동으로 실행하지 않는다.

Space는 대시보드 소유 이동의 정지와 후속 계획 취소, Esc는 제어 해제다. 이미 실행 중인 내장 프리셋은 Space로 중단된다고 보장하지 않는다. 기본 MC와 리모컨이 작동하는 운용 조건에서 댐핑은 L2+R2+Create, 영토크는 L1+R1+Create다. 힘을 해제하기 전 의자·보조자의 지지를 확인한다.

`./stop.sh`는 대시보드 서버를 종료한다. 로봇 전원 종료는 착석·지지 상태에서 제공된 로봇 매뉴얼의 댐핑→영토크→배터리 버튼 짧게 1회 후 약 5초 길게 절차를 따른다.

데이터 스튜디오의 MC 중지·착석 텔레옵은 별도 운용 경로다. 이 대시보드의 내장 프리셋은 안정 서기 API를 사용하며 MC 중지 명령을 보내지 않는다.
